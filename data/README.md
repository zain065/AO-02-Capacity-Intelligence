# Telemetry Data Directory

This folder stores telemetry datasets for the Data Centre Capacity Intelligence application.

- **Synthetic Telemetry**: Generated deterministically by `backend.telemetry` for testing, reproducible demonstrations, and edge case evaluations.
- **Imported Telemetry**: Reserved for public or external telemetry datasets (e.g. Alibaba cluster trace, Google cluster data). All imported datasets must be clearly labeled to distinguish them from synthetic records.
